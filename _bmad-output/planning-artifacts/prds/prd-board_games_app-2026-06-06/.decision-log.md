## Decyzje

### [D-1] 2026-06-06 — Sklepy w MVP
**Kontekst:** Brainstorming definiował MVP = 3Trolle + AlePlanszowki + Mepel. Raport techniczny potwierdził, że Mepel aktywnie blokuje boty (HTTP 403, Cloudflare AI Labyrinth).
**Decyzja:** Opcja B — MVP = 3Trolle + AlePlanszowki. Mepel → Faza 1.5 po pozytywnym teście Playwright.
**Podjął:** Kacper, 2026-06-06.

### [D-2] 2026-06-06 — Klucz deduplicacji produktów
**Kontekst:** Brainstorming zakładał EAN-first. Raport potwierdził, że EAN NIE jest w BGG API i może nie być w listingach sklepów.
**Decyzja:** BGG ID jako primary key deduplicacji. EAN zbierany lazily ze stron produktów jako dodatkowe pole.
**Uzasadnienie:** BGG ID jest zawsze dostępny przez API, stabilny i unikalny per edycja gry.

### [D-3] 2026-06-06 — BGG API wymaga rejestracji (od X 2025)
**Kontekst:** BGG XML API2 wymaga Bearer Token od października 2025. Licencja non-commercial dostępna (bezpłatna).
**Decyzja:** Rejestracja aplikacji w BGG jest pre-requisitem przed implementacją Paszportu Planszówki.
**Status:** OTWARTA — czy Kacper już zarejestrował? Wpływa na timeline.

### [D-4] 2026-06-06 — Stack techniczny (zatwierdzony przez raport)
**Kontekst:** Raport techniczny zweryfikował i zarekomendował konkretny stack.
**Decyzja:** Python 3.11 + Scrapy 2.14 / FastAPI / Next.js 14 App Router / PostgreSQL 16 / Docker Compose / Hetzner VPS (~€5-6/mies.)
**Uzasadnienie:** Sprawdzony dla e-commerce scraping, wystarczający dla hobby scale, jeden deweloper.
**Miejsce:** addendum.md (szczegóły techniczne nie należą do PRD).

### [D-5] 2026-06-06 — Architektura: Modular Monolith
**Kontekst:** Raport odradzał microservices dla hobby projektu jednego dewelopera.
**Decyzja:** Modular Monolith na Docker Compose (scraper + FastAPI + PostgreSQL na jednym VPS, Next.js na Vercel free).
**Miejsce:** addendum.md

### [D-6] 2026-06-06 — RODO/PKE 2024: double opt-in dla alertów email
**Kontekst:** Polska Ustawa PKE z listopada 2024 wzmocniła wymogi zgody dla komunikacji email.
**Decyzja:** Double opt-in obowiązkowy. Suppression list wymagana. Data minimization (tylko email + game_id + próg + token).

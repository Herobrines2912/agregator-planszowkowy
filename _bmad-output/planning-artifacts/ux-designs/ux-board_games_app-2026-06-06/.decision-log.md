# Decision Log — UX Board Games App
_Created: 2026-06-06_

---

## Sesja 1 — Paleta i identyfikacja wizualna

### DEC-01 — Kierunek estetyczny
**Decyzja:** B — Enthusiast magazine / klimat społeczności  
"Przytulny, ciepły, zrobiony z pasji dla innych." Nie korporacyjny deal-agregator.

### DEC-02 — Motywy (light/dark)
**Decyzja:** Jasny domyślny. Dark mode zaplanowany na Fazę 2.  
Dark wariant: głęboki brunat/sepia (nie czarny) żeby zachować ciepło.

### DEC-03 — Typografia
**Decyzja:** Serif nagłówki (Playfair Display) + DM Sans body  
Klasyczny duet magazine — ciepło w nagłówkach, czytelność w danych.

### DEC-04 — Paleta kolorów (finalna)
**Decyzja:** Wariant "Stara Biblioteka" rozjaśniony do "Pergamin" z kartą z wariantu A

| Token | Hex | Rola |
|---|---|---|
| Background | `#F2EAD8` | Tło strony — pergaminowy krem |
| Card surface | `#EDE5D4` | Tło kart — lniany krem |
| Accent green | `#3D5C3A` | Główny akcent: przyciski, nagłówki |
| Primary text | `#2C1F14` | Główny tekst |
| Secondary text | `#6B5744` | Tekst pomocniczy, metadane |
| Border | `#D4C4AE` | Linie, separatory |

### DEC-05 — Semantyczny system badge'y rabatowych
**Decyzja:** Kolor badge'a zależy od wartości rabatu:
- `< 40%` → zielony `#3D5C3A`, biały tekst
- `40–70%` → bursztyn `#C07B18`, biały tekst
- `> 70%` → czerwień `#C42B2B`, biały tekst

### DEC-07 — Form factor i strategia platform
**Decyzja:** Desktop-first w developmencie (łatwiej budować). Mobile responsive do MVP. Natywna aplikacja mobilna jako osobna faza — w momencie launczu mobilki porzucamy część desktop i lecimy full mobile.  
Implikacja: komponenty projektowane "mobile-aware" od początku.

### DEC-08 — Nawigacja główna
**Decyzja:** Slim sticky header (64px) + filter strip pod spodem.  
Header: logo (lewo) + searchbar (centrum) + Flipper Mode button + hamburger ☰ (prawo).  
Filter strip: "⚙ Filtry (n)" button + aktywne tagi z × + licznik wyników + view toggle (Karty/Lista) + Sortuj dropdown.  
NIE: sidebar, NIE: rozbudowany portal-nav.

### DEC-09 — System widoków feedu
**Decyzja:** Dwa tryby na stronie głównej, przełączane togglem:
- **Karty** (domyślny): grid 4 kolumny, duże obrazki, pełna karta
- **Lista**: kompaktowe wiersze, miniatura 48px, wszystko widoczne bez scrollowania

### DEC-10 — Game Passport struktura
**Decyzja:** Kolejność sekcji: Hero (okładka + meta BGG) → DLC warning (jeśli dotyczy) → Opis skrócony (2 zdania, italic serif) → Pełny opis (3 akapity) → Porównanie cen → Historia cen (SVG chart) → Info BGG (na dole).  
Usunięty: chip "BoardGameGeek" w nagłówku — redundantny.  
"Waga" → "Trudność" w siatce metadanych (bardziej zrozumiałe dla casual userów).

### DEC-11 — Email Alert flow (3 kroki)
**Decyzja:** Modal (nie osobna strona). Trzy stany:
1. Formularz: próg cenowy + email + checkbox Type B alert
2. Pending: "sprawdź skrzynkę" (double opt-in wymagany przez RODO/PKE 2024)
3. Sukces: potwierdzenie aktywnego alertu + sugestie innych gier  
Brak konta — email jednorazowy do alertu.

### DEC-12 — Flipper Mode
**Decyzja:** Gęsta tabela transakcyjna (nie karty). Kolumny: Gra | Cena | Rabat | Śr. hist. | Margin Proxy (z kierunkowym wskaźnikiem ↑→↓) | Trend sparkline | Akcja.  
Banner "aktywny tryb" na zielonym tle na górze strony. Przycisk Flipper Mode w headerze przechodzi z outline → filled gdy aktywny.  
Explainer Margin Proxy zwinięty na dole tabeli.

### DEC-06 — Badge "HOT"
**Decyzja:** Terakota `#C4622D`, biały tekst, styl "przyklejona naklejka" obrócona ~-4deg, subtelny cień.  
NIE: wielki czerwony napis. NIE: zielony (wtapia się w przycisk).
